# Helmer API

Python (`import helmer`) and C++ (`#include "helmer/whitney.hpp"`, namespace `helmer`). Polynomials have
rational coefficients and are written as strings: `"3/2*x^2*y - z + 7"` (`+ - * ^`, integer powers, rational
constants). Ideals are generated by such polynomials.

## Rings, polynomials and ideals

| Python | C++ | |
|---|---|---|
| `Ring("x, y, z")`, `Ring(["x", "y", "z"])` | `Ring::make({"x", "y", "z"})` | ℚ[x, y, z]. `R.variables`, `R.nvars`. |
| `Poly(R, "x^2 - y")` | `Poly(R, "x^2 - y")` | `+`, `-`, `*`, `==`, `total_degree()`, `factor()` (irreducible factors over ℚ, with multiplicities). |
| `Ideal(R, ["x^2 - y", "y*z"])` | `Ideal(R, {Poly(R, ...), ...})` | Generators as strings or `Poly`; `I.gens` returns strings. |
| `I.groebner_basis()` | `I.gb()` | Reduced Gröbner basis, degree reverse lexicographic. |
| `I.dim()`, `I.codim()`, `I.is_unit()` | same | Krull dimension and codimension of ℚ[x]/I (`dim` of the unit ideal is −1). |
| `I.independent_set()` | `I.independent_set()` | A maximal independent set of variables. |
| `I.contains(J)`, `I.contains_poly("f")` | `I.contains(J)`, `I.contains(f)` | Ideal membership. |
| `I + J`, `I == J`, `hash(I)` | `I + J`, `I.equals(J)` | Sum; equality of ideals (not of generators). |

## Whitney stratification

```python
whitney_stratify(ideal, projective=False, level=-1, saturation="random", log=None,
                 method="conormal", polar_bound=1000, minimal=False) -> {dim: [Ideal, ...]}
```

The closures of the strata, by dimension, as prime ideals over ℚ. The open strata of dimension d are the
connected components of V(P) minus the closures of lower dimension, for each P in `result[d]`. Over ℝ the
same ideals give a valid stratification of the real points (strata may be empty, or of lower dimension).

* `projective=True`: the generators are homogeneous and V(I) lies in projective space; dimensions are
  projective.
* `method="conormal"` (default): the conormal algorithm of Helmer–Nanda in the associated-prime-free form of
  Helmer–Mohr (Macaulay2 `whitneyStratify(I, AssocPrimes=>false)`). Deterministic up to the modular lift of
  Gröbner bases. `method="polar"`: polar varieties (`whitneyStratifyPol`): random linear projections with
  coefficients in [−`polar_bound`, `polar_bound`]; a valid, generally non-minimal stratification.
* `level`: how many levels to descend from the top dimension (−1: all).
* `saturation`: how conormal varieties are saturated. `"random"` (default) uses a hyperplane chart when one
  exists and otherwise a single sparse minor; `"minor"` always a single minor; `"exact"` the intersection
  over all minors (slow; for checking).
* `minimal=True`: coarsen the result to the minimal Whitney stratification (`min_coarsen`, below).
* `log`: a function called with progress messages, e.g. `log=print`.

C++: `Stratification whitney_stratify(const Ideal&, const WhitneyOptions& = {})`, with the same options as
fields of `WhitneyOptions` and the result in `Stratification::strata` (`std::map<int, std::vector<Ideal>>`).

## Multiplicities and minimal stratifications

```python
min_coarsen(strata, projective=False, trials=2, log=None) -> {dim: [Ideal, ...]}
multiplicity(X, Y, trials=2) -> int
polar_sequence(X, Z, trials=2) -> [int, ...]
polar_multiplicity(X, Z, dim, trials=2) -> int
in_singular_locus(X, Y, trials=2) -> bool
contained(X, Y, trials=2) -> bool
```

* `min_coarsen(strata)`: the minimal (coarsest) Whitney stratification refined by `strata`, which must be a
  Whitney stratification with prime closures (e.g. `whitney_stratify`'s output). The same as
  `whitney_stratify(I, minimal=True)`. Macaulay2: `minCoarsenWS`.
* `multiplicity(X, Y)`: the Samuel multiplicity e_X(Y) of V(Y) along the irreducible V(X), i.e. the
  multiplicity of Y at a general point of X; only the components of Y of largest dimension through X count; 0
  if X is not in V(Y). Homogeneous input is read as affine cones (the same multiplicities).
* `polar_sequence(X, Z)`: for a prime Z of dimension d, the multiplicities at a general point of X of the
  generic polar varieties of Z of dimensions 0, …, d (the last is e_X(Z); entries are 0 where X is not in the
  polar variety). `polar_multiplicity(X, Z, w)` computes entry w alone. Macaulay2: `polarSequence`.
* `in_singular_locus(X, Y)`: V(X) ⊆ Sing V(Y), for X irreducible and Y prime (e_X(Y) > 1).
* `contained(X, Y)`: V(X) ⊆ V(Y), i.e. Y lies in the radical of X. For containment of ideals use
  `X.contains(Y)` (exact).

All of these are Monte Carlo: they are values at a general point, computed over F_p for random 31-bit primes
p with random slices, and repeated until `trials` independent runs agree (an error is raised if they keep
disagreeing). `helmer.set_seed` makes them reproducible.

C++: `helmer/multiplicity.hpp` (`min_coarsen`, `multiplicity`, `polar_sequence`, `polar_multiplicity`,
`in_singular_locus`, `contained`, with `LocalOptions{trials, max_runs, max_pointless_primes}`).

## Maps

```python
map_stratify(F, X, Y, proper=True, strata="all", log=None) -> (strata of X, strata of Y)
non_proper_set(F, X, Y) -> Ideal
```

`F` lists the components of a polynomial map f: X → Y, as polynomials in the ring of `X`; `Y` is an ideal in
the target ring (`Ideal(S, [])` for all of it). The result stratifies X and Y so that f maps each stratum of
X submersively onto a stratum of Y; by Thom's isotopy lemma the fibres over each stratum of Y are then
topologically the same. With `proper=False` the set over which f is not proper (Jelonek) is added to the
target strata; `non_proper_set` returns it alone. Macaulay2: `mapStratify(F, X, Y, AssocPrimes=>false)`,
`nonProperSet`.

## Commutative algebra

| function | |
|---|---|
| `minimal_primes(I)` | The minimal primes of I over ℚ (Macaulay2 `decompose`); each is certified prime. |
| `eliminate(I, ["x", "y"])` | I ∩ ℚ[other variables], as an ideal of the same ring. |
| `saturate(I, J, strategy="random")` | I : J^∞. |
| `intersect(I, J)` | I ∩ J. |
| `conormal(I, saturation="random")` | The conormal variety of V(I) in kⁿ × ℙⁿ⁻¹, with dual coordinates `v_0, …, v_{n−1}`. |
| `polar_varieties(I, bound=1000)` | The polar varieties of a prime I (Macaulay2 `polarVars`). |

## Certified membership and elimination

| function | |
|---|---|
| `certify_membership(I, f, block=[], max_unknowns=4000, max_primes=64)` | Cofactors c_j with f = Σ c_j g_j over the generators g_j of I, as a dict (`target`, `generators`, `cofactors`, `bounds`), checked exactly over ℚ before it is returned; `None` if none was found within the limits (which proves nothing). |
| `verify_membership(I, f, cofactors)` | Exact check of f = Σ c_j g_j; `I` may also be a list of generators, with `ring=`. |
| `eliminate_certified(I, ["x", "y"])` | `eliminate(I, …)` and, for each generator, a certificate as above (or `None`). A certified generator vanishes on V(I). |

## Reproducibility and statistics

`set_seed(n)` seeds the random primes of the Gröbner lifts and the random geometric choices (charts, polar
projections), so that a run can be repeated. `stats()` returns counters: Gröbner calls, F4 runs, unlucky
primes, seconds in Gröbner bases, prime decomposition calls.

## Command line

```
helmer [--vars x,y,z] [--projective] [--method conormal|polar] [--seed n] [--json] [-v] EQUATION ...
```

Stratifies the variety of the equations and prints the strata by dimension (`--json`: as
`{dimension: [[generators], ...]}`). Without `--vars`, the variables are the names in the equations, sorted.
`python -m helmer` is the same.
